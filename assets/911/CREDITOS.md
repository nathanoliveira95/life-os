# Modelo 3D — Porsche 911 Carrera 4S

- **Título:** (FREE) Porsche 911 Carrera 4S
- **Autor:** Karol Miklas — https://sketchfab.com/karolmiklas
- **Fonte:** https://sketchfab.com/3d-models/free-porsche-911-carrera-4s-d01b254483794de3819786d93e0e1ebf
- **Licença:** CC BY-SA 4.0 — https://creativecommons.org/licenses/by-sa/4.0/

Este arquivo (`porsche-911-carrera-4s.glb`) é a versão otimizada (glTF-Transform + Draco)
publicada no repositório pmndrs/examples (`examples/building-live-envmaps/src/911-transformed.glb`).
No site, o modelo é dividido em painéis para a animação de montagem e os materiais
(pintura preta, vidros fumê, pneus, luzes) são ajustados em tempo de execução. O arquivo do modelo
continua distribuído sob a mesma licença CC BY-SA 4.0.
